## Finalidade

O campo de vídeo permite selecionar um arquivo de vídeo de uma pasta de mídia.
Ele também permite selecionar uma imagem para atuar como pôster do vídeo,
geralmente o primeiro quadro do vídeo.

## Criação do campo

Os parâmetros comuns dos campos são descritos em um artigo separado.

* **Título** O título é visto e usado na lista de campos.
* **Rótulo** É o que é exibido na saída. Se deixado vazio, ele é definido
a partir do conteúdo do campo Título, mas pode ser alterado.

![criação do campo de vídeo](../../../en/images/fields/adding-custom-fields-video-field/01-fields-video-edit.png)

**Observação:** Neste exemplo, a inclusão do tipo de campo no Título serve apenas
para fins de demonstração. Não o inclua nos títulos dos seus próprios campos.

## Entrada de dados

Em uso, o campo de vídeo é simples. Você seleciona o arquivo de vídeo necessário usando um
seletor de mídia. 

A captura de tela a seguir mostra um arquivo de áudio selecionado:

![entrada de dados do campo de vídeo](../../../en/images/fields/adding-custom-fields-video-field/02-fields-video-data-entry.png)

Os campos só aparecem em um artigo se forem preenchidos no formulário de entrada de dados do artigo.

## Exibição dos dados

A captura de tela a seguir do site mostra o campo exibido em um artigo. A
opção *Exibição automática* é responsável pela posição do campo, e o seu
template é responsável pelo design do campo.
